## 03 — 🛡️ Shieldify

### `AI-Powered Web Application Firewall`

**Shieldify** is a cybersecurity-focused SaaS concept designed to protect
web servers from potentially malicious HTTP requests.

It explores the idea of a protective layer between the internet and a
customer's server for analysing and handling suspicious traffic.

### Security Capabilities

* 🛡️ Web Application Firewall
* 🤖 AI-assisted threat detection
* 🚨 Threat detection & blocking concepts
* 🔍 Anomaly detection
* 🧠 Adaptive security approach
* 🚦 Rate limiting
* 🚫 IP blocking
* 🧹 Request sanitization
* 📊 Security analytics

### Tech

`Next.js` `TypeScript` `Tailwind CSS` `Node.js` `API Routes`

## 03 — Shieldify

### `AI-Powered Web Application Firewall`

**Shieldify** is a cybersecurity-focused SaaS project designed to protect
web servers from malicious HTTP requests.

It works as a protective layer between the internet and a customer's server,
analysing incoming traffic and detecting potentially malicious requests.

### Security Capabilities

- 🛡️ Web Application Firewall
- 🤖 AI-assisted threat detection
- 🚨 Real-time threat blocking
- 🔍 Anomaly detection
- 🧠 Adaptive/self-learning approach
- 🚦 Rate limiting
- 🚫 IP blocking
- 🧹 Request sanitization
- 📊 Security analytics

### Tech

`Next.js` `TypeScript` `Tailwind CSS` `Node.js` `API Routes`

### 🔗 Repository

https://github.com/Vivek4320/VikasSaptah2025-Shieldify
